Pharmacy App UI/UX Design

A UI/UX design project for a pharmacy mobile application created using Figma. The prototype focuses on providing a simple and user-friendly experience for browsing products, uploading prescriptions, ordering medicines, and tracking deliveries.

Features

Welcome page
Login and Sign Up
Home page
Skin Care section
Hair Care section
Baby Care section
Medicine section
Search functionality
Prescription upload
Confirmation message after prescription submission
Shopping cart
Payment method selection
Payment success message
Order tracking
Order cancellation
Profile page
