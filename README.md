# PHARMACY | فارماسي — Interactive Prototype

A responsive Arabic-first pharmacy shopping prototype built with plain HTML, CSS, and JavaScript.

## Run on a computer
1. Extract `PHARMACY.zip`.
2. Open the `PHARMACY` folder in Visual Studio Code.
3. Install the **Live Server** extension.
4. Right-click `index.html` and choose **Open with Live Server**.

You can also open `index.html` directly in a modern browser; Live Server is recommended.

## Use on iPhone
The easiest method is to publish the folder using GitHub Pages:
1. Create a GitHub repository named `pharmacy-prototype`.
2. Upload the files in this folder (index.html, styles.css, app.js, README.md) to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select **main** and **/(root)**, then Save.
5. Open the generated Pages URL on your iPhone.

## Included
- Home, shop, categories, product detail, search, cart, checkout, confirmation, tracking, prescription demo, account, wishlist, help.
- Working navigation, product search/filter/sort, cart quantities, wishlist, theme switch, demo checkout, localStorage persistence.
- Responsive layout for desktop and mobile.

## Important
This is a front-end demonstration only. It does not process payments, create real user accounts, transmit prescription files, provide medical advice, or connect to a backend. Product names, imagery, and prices are demo content.
